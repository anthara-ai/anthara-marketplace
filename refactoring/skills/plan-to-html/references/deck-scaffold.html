R2Introduce the CodeProvider seamExtract Interface
What

Name the three methods AssessmentService calls on the SNOMED client as an interface, and make the client implement it.

Why

The problem statement's path runs through this call. Every provider added today means a new branch here.

Check

Type check and build. The export list diffs clean. T1 stays green.

Undo

Revert the commit. Nothing else depends on it until R3.

Risk · medium, runs blind

No test drives this call directly until T2 lands in the next step. The move is mechanical and compiler-checked, which is why it is allowed to go first.

The decisions this room can make

Is the LOINC export public? It may be used outside this repository. If not, R7 can rename it. If so, R7 moves to the leave-alone list.
